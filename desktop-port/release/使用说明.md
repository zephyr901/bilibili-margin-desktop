# 映间 MARGIN · B 站 Windows 桌面整合版 0.2.0

基于 B 站 Windows x64 客户端 1.17.6 和映间 MARGIN v0.52.0。解压后可直接运行。包内包含所需运行文件，无需另外安装 B 站、Node.js 或浏览器扩展。

1. 把 ZIP 完整解压到本地可写目录，保留 `client` 子目录。
2. 双击 **启动映间.cmd**。首次使用时按客户端界面完成首次启动流程。在线播放、搜索、评论和天气需要网络。
3. 登录后可使用账号相关功能。登录状态和设置保存在当前 Windows 用户的 `%LOCALAPPDATA%\MARGIN-Bilibili\DesktopProfile`。每台设备各自登录。设置里的「导出／导入」用于迁移映间设置和足迹。

用顶部的「映间首页」返回映间首页，用「原生界面」切换到客户端原生界面。播放器小窗由标题栏按钮进入，小窗中可点「还原」「关闭」，也可以按 Esc 还原。展开评论下的「共 N 条回复」可查看回复树。减少动态效果设置会暂停搜索粒子。

本包适用于 Windows x64。它是独立的映间桌面适配版，版本更新时请先退出本版，再解压替换程序文件。`MANIFEST-SHA256.txt` 列出包内文件的校验值。功能覆盖和实际验证范围见《功能验收.md》。

2026-11-06 热补丁修复了登录后首页头像与收藏夹不同步、搜索结果卡片闪动。更新后继续使用原有账号和设置目录。

上游及其许可证见 [MARGIN v0.52.0](https://github.com/jiuyang5354/bilibili-margin/releases/tag/v0.52.0) 和 `licenses`。Electron 与 Chromium 的许可证位于 `client` 目录。
