# 映间桌面版 0.2.0 功能验收

验收以 GitHub 上的映间 v0.52.0 功能清单为基准。桌面版沿用 B 站 Windows 客户端 1.17.6 的播放器、登录和搜索结果，并在这些界面上接入映间。实机联网测试使用 Windows 11 x64 上的独立访客配置。 [MARGIN v0.52.0](https://github.com/jiuyang5354/bilibili-margin/releases/tag/v0.52.0)

| 上游模块 | 桌面版覆盖及验收情况 |
| --- | --- |
| 首页与搜索 | 推荐、热门、连续加载、换一批、联想、热搜和本地搜索记录沿用映间组件。访客首页实测加载推荐和热门视频。用中文关键词查到真实结果，浅色与深色下都保留映间顶栏和主题，视频分类可切换。输入和退格均检测到粒子画面，点击「映间首页」可返回。 |
| 内容过滤 | 搜索视频卡片与播放器侧栏接入关键词、正则、UP 主、播放量、时长和广告过滤。搜索测试命中一张指定卡片，其余结果仍显示。 |
| 原生播放 | 保留清晰度、弹幕、选集和互动入口。实测公开样片播放进度增长，`X`／`C`／`Z` 倍速快捷键及宽屏、网页全屏均生效。可手动进入小窗，并从小窗直接还原或关闭。 |
| 评论区与互动 | 三条真实评论的回复预览显示树形连线。展开回复的两种容器通过结构测试，覆盖长数字 ID、父子连线和关闭样式后的清理。长按点赞的一键三连动效接入了原生按钮状态。 |
| 收藏与稍后再看 | 收藏文件夹、稍后再看、卡片菜单和预览沿用映间组件。文件夹内容、观看进度及新增、移除等账号操作需要登录。 |
| 足迹与数据迁移 | 首页足迹卡片可显示。年／月热力图、首次打开时间、停留时长和历史补全沿用映间逻辑。实测导出了含设置和足迹的 JSON 文件，重新导入后设置生效。自定义背景图片需要单独带到新设备上。 |
| 阅读与账号页面 | 实测内置页面在映间主题下加载了公开个人空间和图文。观看历史、动态流与消息页均显示对应的登录入口。 |
| 外观与快捷操作 | 首页支持亮色、暗色及跟随系统，并保留动态背景、图片、强度、列数、排布、字体、命令面板与头像工牌入口。13 款背景的 WebGL 程序均通过编译和链接检查。当前桌面运行时的汇流背景使用 WebGL 渲染。 |
| 天气 | 首页显示天气数据，城市列表可以搜索并切换。实测选择苏州后，天气卡片显示所选城市。 |
| 实验功能 | App 推荐的未登录接口实测返回 15 条数据。扫码授权后的推荐、个性重排及负反馈需要相应账号数据和在线服务。 |

账号验收限于访客访问与入口检查，登录后的账号数据和写入操作待用实际账号验证。视频的可见性、清晰度和弹幕也受 B 站权限与服务状态影响。

桌面版用「原生界面」入口切回 B 站界面。浏览器扩展弹窗和商店更新属于扩展的安装方式。桌面版从本 ZIP 解压，后续版本可退出程序后替换程序文件。
